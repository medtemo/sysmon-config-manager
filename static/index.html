Help & Manuals

    

      
What this is

      
A visual editor for Sysmon configuration XML - browse, add, and edit detection rules
      by event type without hand-writing XML, with live validation and change tracking.


      
Include vs. Exclude

      
Every event type (e.g. ProcessCreate) has two independent buckets:

      
    
        
  • Include - only events matching one of these rules get logged.
    • 
        
  • Exclude - events matching one of these rules get filtered back out,
        even if something in Include matched them.
    • 
      

      
Rules within the same bucket are OR'd together - any single match is enough to trigger it.


      
Flat rules vs. nested groups

      
    
        
  • Flat rules sit directly under Include/Exclude, each one independent (OR logic).
    • 
        
  • Nested groups (+ Add Group) bundle several conditions with their
        own AND/OR relation - use AND when a detection needs multiple conditions true at once
        (e.g. a specific parent image AND a specific command line).
    • 
      


      
Active schema

      
The schema (top of the window) determines which event types, fields, and conditions are
      offered while you edit, and what Validate checks against. Switch it to match the Sysmon
      version you're targeting, or use Upload… to add one exported via
      sysmon.exe -s for a version not already available.


      
Global settings

      
The Settings button (top right) covers config-wide options that apply to
      the whole file, not any one event type:

      
    
        
  • Hash Algorithms - which hash(es) Sysmon computes for created/loaded
        images (e.g. SHA256, MD5, IMPHASH, or all).
    • 
        
  • Check Revocation - whether Sysmon checks a signed image's certificate
        for revocation.
    • 
        
  • DNS Lookup - whether Sysmon resolves IP addresses to hostnames in
        network events.
    • 
        
  • Archive Directory - the folder name (under C:\) where
        deleted or overwritten files are preserved.
    • 
      


      
Changes, Apply, and Export

      
    
        
  • The Changes panel tracks every add/edit/delete since the file was
        opened, and can revert any single change.
    • 
        
  • Apply Changes accepts the current state as the new baseline and clears
        that list - it's bookkeeping only, it does not touch your OS or the live Sysmon service.
    • 
        
  • File → Export Bundle… downloads the config together with SHA256/MD5
        hashes and a full changelog of everything applied - useful as an audit record before
        handing a config off or deploying it.
    • 
      


      
Finding things

      
Use the sidebar to jump between event types, Filter rules… to search within
      one, and Validate to catch common mistakes (invalid conditions, fields not in
      the active schema, empty rule groups) with a direct link to each one.
